# 开发计划与版本范围

项目：观澜 Invest Watch / Docker Hub 目标 `stylle/money-web`。

## 已确认的产品方向

个人自部署，React + TypeScript / FastAPI / SQLite / 单容器内独立 worker 进程 / Docker Compose。
以股票、场内 ETF 与加密现货为对象，A 股、港股、美股、加密市场分别搜索订阅。持仓不存金额，总资产划分为 100 份，现金也计入。
默认仅行情观察；程序建议和 AI 分别开启。只有投资分析调用 AI。
“交易日不通知”按前轮明确提出的“非交易日不通知”实现，可由用户继续调整。

## v0.1 实现

- 中文响应式工作台，七个页面，行情图表、标的详情、四市场搜索及手动完整代码订阅。
- 自选 CRUD、每个标的阈值、报价时间和错误展示。最多 50 个自选。
- RSS / Atom 多源、标题规范化去重、关键词方向订阅、原文链接，无 AI 新闻生成。
- 八个已实测可解析的内置资讯适配器（财联社、证券时报、金十公开市场参考、华尔街见闻、TradingView 社区观点、Seeking Alpha、CoinDesk、Cointelegraph）；雪球已列出但当前需授权，未假装可用。支持健康状态及来源独立退避。
- 腾讯/东方财富 A 股、腾讯港美股及 Yahoo 主备节点自动切换，保留行情时间；来源异常不清空原缓存。报价/历史/分时标明独立来源，不混接复权行。
- 加密现货 Binance / Coinbase 公开行情，同一交易对故障切换；USD / USDT 不互换；全天监控，上一 UTC 日收盘涨跌幅，UTC 日线与北京时间 08:30 日报；独立加密资讯频道。
- 100 份持仓快照；可选目标比例、单标的上限、现金下限、单次调整上限、风险偏好和投资周期。并发版本保护和修改记录。临时金额计算器仅前端内存。
- 完整日线 MA20/MA60、RSI、MACD、ATR、历史量比；多条件确认；禁止基于不足、过期、含未完成日线的数据给出操作提示。
- 同批程序建议共享当前现金预算，不使用尚未执行的减仓融资。
- 交易日历、午间休市、美股夏令时、半日市；开盘后 30 分钟日报，最多迟到 15 分钟；每轮监控后等待 60 秒，不是秒级行情服务。
- 较昨收 ±N% 阈值，阈值倍数分档、同标的同交易日同方向同档去重。风险提醒与 AI 分离。
- 通用 JSON Webhook、签名、重试三次、去重键、静默时段、过期丢弃、发送记录。
- 可选 Chat Completions / Responses 兼容接口，连接测试，UTC 每日调用上限，AI 结构及仓位约束校验、引用 ID 校验、失败降级。
- 加密设置、口令鉴权、外部地址校验、任务租约、健康检查、GitHub CI / Docker 发布脚本。
- 本地持续试用启动/停止脚本；接口超时和断连提示，设置及搜索原地重试，不把请求失败展示为空结果或无限加载。

## v0.2 单容器部署

- 默认 SQLite，单容器包含网页/API 和后台监控，无外部数据库依赖。
- PID 1 管理进程、转发停止信号、子进程失败整体退出；网页和 worker 独立心跳健康检查。
- SQLite WAL、锁等待、独占运行锁；重启恢复遗留任务租约。
- 最简注释 Compose、可选参数、升级与完整数据卷备份说明；旧三容器配置保留为 legacy。
- 不包含 PostgreSQL 到 SQLite 的自动迁移工具；已有数据不得直接覆盖或误挂载。

## v0.2.1 NAS 启动兼容

- 自动准备数据卷权限，支持 PUID/PGID，准备后立即降权；保留已有数据库及密钥内容。
- 限定权限处理范围，拒绝链接和系统目录；启动日志显示失败阶段。
- NAS ACL / 只读挂载不承诺可绕过；按阶段诊断，不再只输出 PermissionError。

## v0.2.2 MagicPush 与 Webhook 兼容

- 标准 MagicPush URL 自动适配 title/content/type=text；支持显式选择与原始事件模式。
- 参照 today-random-movie-web 支持请求方法、JSON/纯文本模板、自定义请求头；安全转义与保存前校验。
- 模板/请求头加密和读取脱敏，HMAC 对实际发送字节签名；统一测试和后台投递路径。
- MagicPush 业务失败与部分渠道失败不当作成功；错误只匹配固定诊断，不回显上游正文。
- 保存并测试只更新 Webhook 设置；未保存其他偏好保留。真实用户渠道联调仍需用户点击测试。

## v0.2.3 出站代理与 NAS 网络诊断

- 统一行情、搜索、资讯、AI、Webhook 的环境代理路由，HTTP/HTTPS/ALL_PROXY 与 NO_PROXY，兼容小写及 NAS 连字符变量。
- 域名边界、端口、IPv4/IPv6 和 IP 字面量 CIDR 直连排除；目标安全限制不因代理放宽，证书验证保留，代理失败不回退直连。
- 本地固定代理连接/认证/超时诊断，不记录代理凭证；健康检查始终直连。
- NAS 宿主机网关/局域网代理 Compose 示例、环境变更重建说明，无密钥容器诊断命令。
- 实际 NAS 和用户代理仍需部署环境验证，不承诺代理本身或各公开行情网站持续可用。

## v0.2.4 持仓保存与行情观察测试

- 持仓只提交可编辑字段，不回传服务器更新时间或计算器金额；保留严格校验与 revision 并发保护。
- 前端以整数百分位校验 100 份、空值、小数精度、仓位上限，不再仅凭合计正确允许保存。
- 在偏好设置预览已保存行情和持仓，再手动发送一次观察测试；与正式日报共用快照结构和 Webhook 适配器。
- 测试标记清晰，显示报价时间、来源、交易状态、缺失/过期标记；不刷新行情、不调用 AI、不消耗日报去重键。
- 手动测试忽略定时、静默和通知开关，仅点击发送时投递一次，成功/失败记入提醒中心，不进入自动重试队列。

## 后续版本，未冒充已实现

1. 获授权行情源的直接适配（目前为腾讯、东方财富、Yahoo 的公开网站端点及自定义标准协议）。
2. 数分钟快速变化、ATR 自适应触发、突破事件的独立推送；当前 ATR 用于解释，未独立推送。
3. 增加获授权的雪球内容和金十付费快讯、公告适配、新闻市场标签、相似事件聚类。
4. ETF 成分重叠与穿透分析；当前没有成分数据，不能计算真实重叠敞口。
5. 完整含费用滑点的策略回测、新闻时点回放、信号后续表现统计。当前只有日线指标和规则边界测试，不声称策略盈利有效。
6. 从建议直接进入“已执行操作”的差异预览；当前需要在持仓页手动更新并保存。
7. 配置导出导入界面、数据保留策略、数据库增量迁移机制。目前提供备份恢复操作，v0.1 使用建表初始化。
8. 多用户、场外基金、自动交易、期权期货暂不纳入个人版。

## 验收阶段

1. 数据可行性：公开行情/搜索/RSS 真网络探测，保存 `source-probe.json`，明确延迟和授权限制。
2. 本地闭环：实际打开网页检查搜索订阅、持仓、设置；后端规则边界测试及前端生产构建。
3. 容器：v0.2 已通过 Linux 80 项后端测试及单容器故障恢复验收；多架构发布记录见 docker-release.json。v0.1 旧 PostgreSQL 备份恢复仍待实操。
4. 试运行：连续交易日核对开盘日报、通知到达率、行情延迟和失败恢复，再决定是否启用建议。

v0.2 镜像发布与验收状态见 docker-release.json；真实 AI/Webhook 联调、完整数据库备份恢复及连续交易日观察仍需对应配置与运行时间。
